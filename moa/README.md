# MOA · Moviment i Salut

Web de una sola página para MOA, el proyecto de Patricia Dorado Trainer en Martorell.

- `index.html`: la web completa (HTML, CSS y JS en el mismo archivo).
- `assets/logos-moa/`: logos de MOA en SVG (firma catalana, firma castellana, logotipo y símbolo A) en verde, violeta, crema, carbón y blanco.
- `assets/pdt-logo-*.svg`: logotipo de Patricia Dorado Trainer (negro, color y blanco).
- `assets/favicon.svg`: icono de la pestaña (símbolo A crema sobre violeta).

## Identidad (brandbook MOA, edición 04)
- Colores: crema `#FEF7E5`, violeta `#9242F3`, verde `#3BC65F`, carbón `#2B2D2B`, blanco.
- Tipografías: Bricolage Grotesque (títulos) y Montserrat (texto), desde Google Fonts.
- El verde no se usa para texto sobre crema (contraste insuficiente), solo en gráficos y fondos.

## Pendiente
- Fotos: los huecos marcados como "Foto: ..." se cambian por `<img class="ph" src="fotos/...">` (instrucciones en el propio HTML).
- Horario lunes y miércoles 18:00–19:00: no se ha publicado porque estaba en duda.
- Formulario: abre WhatsApp o el email con el mensaje escrito. Para recibirlo directamente en el correo, conectar un servicio como Formspree.
- Textos legales (aviso legal, privacidad, cookies).
