# Material de la clienta

Carpeta para dejar aquí lo que vaya mandando Cristina: fotos, portadas,
documentos, textos.

**Qué va aquí:** fotos, portadas de libros, textos, reseñas, PDFs para descarga.

**Qué NO va aquí:** currículums o documentos con NIE, DNI, dirección particular
o cualquier dato personal que no vaya a ser público. Esto es un repositorio y
todo lo que se sube queda en el historial aunque luego se borre.

**Vídeos:** no subirlos aquí. Pesan mucho y GitHub no es un buen sitio para
servirlos. Mejor a YouTube (pueden ser «no listados») y pasar el enlace.

Una vez procesado el material, las imágenes finales van a `assets/img/` ya
optimizadas, y esta carpeta queda solo como archivo de los originales.
