# design-input

Carpeta para los exports del diseño de Figma (`WEBSIDE_BLOMSTRA`).

Deja aquí:

- `home-desktop.png`, `home-mobile.png`, … — frames exportados a 2x
- `tokens.md` — colores, tipografías y medidas copiados de Dev Mode
- `assets/` — logo e imágenes en su resolución original

Ver [../docs/INTAKE-DISENO.md](../docs/INTAKE-DISENO.md) para el detalle de
cómo exportarlos.
